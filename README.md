# Agri Leaf Diagnosis

🌿 **Agri Leaf Diagnosis** is a machine learning-based tool for detecting and classifying plant leaf diseases to help farmers take preventive measures.

## 🚀 Features
- Image-based disease detection
- Supports multiple plant species
- Provides treatment suggestions
- Web-based interface

## 🛠 Technologies
- Python, TensorFlow, Keras
- OpenCV, NumPy, Pandas
- Flask (Web App)

## 📌 Usage
- Upload a leaf image.
- Get disease classification & remedy suggestions.

## 🔮 Future Plans
- Mobile app integration
- Larger dataset & model improvements
